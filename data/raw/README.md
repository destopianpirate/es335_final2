# data/raw

Put the five CSV files of the Kaggle [Customer Retention Datathon (Riyadh Edition)](https://www.kaggle.com/competitions/customer-retention-datathon-riyadh-edition/data) data here:

| file | size |
|---|---|
| `train_data.csv` | 44 MB |
| `kaggle_test_data.csv` | 1 MB |
| `members.csv` | 428 MB |
| `transactions.csv` | 115 MB |
| `user_logs.csv` | 1.4 GB |

They are not committed (too large for GitHub, and the competition data is distributed by Kaggle). See the main README for where to get them.
