1. 01

    Get the data

    Download the five CSVs from Kaggle (accept the competition rules first) and put them in data/raw/. The README lists which Kaggle file becomes which name.

  2. 02

    Install

    Clone the repository, then install. Python 3.11 or newer; exact versions are pinned in requirements.txt.

    git clone {{REPO_URL}}.git
cd es335_final2
pip install -r requirements.txt
  3. 03

    Run the notebooks

    In this order; 08 runs before 07 because 07 exports its results. About 30 minutes and 8 GB of RAM in total.

    cd notebooks
for nb in 01 02 03 04 05 06 08 07; do
  jupyter nbconvert --to notebook --execute --inplace ${nb}_*.ipynb
done
cd ..
    1. 01raw_data_analysisthe 5 raw tables
    2. 02feature_engineeringone row per subscriber, 33 features
    3. 03feature_analysis_and_split70 / 10 / 20 split, feature plots
    4. 04baselinesmajority, rule, logistic regression
    5. 05tree_models_and_tuningrandom forest, LightGBM + Optuna, threshold, ablation
    6. 06test_evaluationtest metrics, curves, bootstrap, errors
    7. 08strict_cutoffbilling cut at 1 March (run before 07)
    8. 07website_exportnumbers and the browser model for this site
  4. 04

    Export the extra tables

    Data Studio tables that need the raw files, and every model scored on validation and test.

    python scripts/export_ds_extra.py
python scripts/export_val_test_metrics.py
  5. 05

    Build and open the site

    Writes the site to docs/ and serves it locally.

    python website/build.py
python -m http.server 8000 -d docs   # open http://localhost:8000
  6. 06

    Check (optional)

    The browser model should match Python, and results/test_metrics.csv should show the tuned LightGBM at PR-AUC 0.9644. Seeds are fixed, but training uses all CPU threads, so the last decimal places can differ on another machine.

    node website/tests/check_model_parity.mjs

Metric tables: test_metrics.csv · validation_metrics.csv · val_test_metrics.csv · model_comparison.csv · strict_cutoff_metrics.csv. Setup details, data access and citations: README.
