Could the model be seeing the answer?

Leakage is when a feature carries information the model would not have at prediction time, or carries the label itself. It makes scores look better than they will be in use. We checked each way it could enter this project.

What each cutoff can see

The labelled plans expire during March, so a model frozen on 31 March already sees most renewal payments. Cutting billing at 1 March removes them. Same tuned LightGBM, same test subscribers. Click a model box for the evidence.
