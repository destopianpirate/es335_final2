07Limitations/ 09

What these results do not show

The 31 March scores are optimistic for early warning

KKBOX defines churn from transactions, and the labelled plans expire during March, so the last March transaction often already shows the renewal decision. The headline PR-AUC means "easy once billing shows the decision", not "we can read intentions". With billing cut at 1 March the model is much weaker (see the strict check).

One snapshot, random split

Train and test subscribers come from the same month. We do not show that the model keeps working for a later month, when prices, promotions or user mix may change.

Hard cases stay hard

Prediction is not causation

Feature importance shows what the model uses, not what makes people leave. For example, switching a subscriber's auto-renew on would not necessarily keep them: auto-renew is partly a sign of an earlier decision to stay. Testing an intervention would need an experiment.

Listening data is thin

Only March 2017 is used, and about a fifth of subscribers have no logs at all. A longer listening history might show a larger effect than our ablation finds.

Threshold and tuning use the same validation split

This makes validation scores slightly optimistic; test scores are not affected because the test split was never used for any choice.

Predictor page is approximate

The predictor runs the real champion model, but asks for 16 inputs; the other features are filled with training medians for similar subscribers. Treat it as an illustration of the model, not a scoring tool. Demographic features (age, city) also raise fairness questions if used for decisions.

Privacy and fairness

Subscriber IDs are anonymised hashes and there are no names or contact details. But age and gender are model inputs, and we did not check whether error rates differ between age or gender groups. Before any real use, audit those groups, and use the scores to offer help to people likely to leave, not to treat them worse.

The Kaggle test set has no labels

The competition test file lists subscribers without the answer. We predict them (results/submission.csv) but cannot score them here, so every number on this page comes from our own labelled test split.
