Train / validation / test

One random split, stratified on is_churn, with a fixed seed (42). Every subscriber lands in exactly one part; the assignment is saved as data/processed/split_assignments.csv so it can be checked.

Train fits every model and every preprocessing step (imputation medians, scaling). Validation compares models, tunes LightGBM and picks the decision threshold. Test is used once, for the final numbers.

All rows come from the same March 2017 snapshot, so this is not a test on a later time period (see Limitations).
