The five raw tables

The KKBOX churn data comes as five CSV files. Two hold the subscribers we predict for; three describe them. We turn every table into one row per subscriber and left-join them, so no subscriber is dropped. The coverage column shows the share of the labelled subscribers who appear in each table.

How the five files become the feature matrices

Each table is cleaned and aggregated to one row per subscriber (msno), then left-joined onto the two ID lists. The labelled subscribers are split into train, validation and test (notebooks 02 and 03). The Kaggle test subscribers get the same 33 features but have no label; the tuned model predicts them into submission.csv (notebook 07). Dashed boxes: the Kaggle test path.

Columns in each raw file

27 columns across the five files (2 + 1 + 6 + 9 + 9). msno is in every file and is the join key. Data types are what pandas infers from the CSV; dates are stored as YYYYMMDD integers and parsed during feature engineering.

How we joined them

The files have different shapes: one row per subscriber, per payment, or per day of listening. Each file is first reduced to one row per subscriber, then all three are left-joined on msno onto the ID list, in the order members → transactions → user_logs. A left join keeps every subscriber in the list, even one missing from a file, so the matrix keeps exactly 946,686 labelled rows (and 24,274 Kaggle test rows, built the same way). Notebook 02.

After the join, every feature is stored as float32; the gaps that remain (age, city, the latest-transaction fields) are filled inside each model on the training split only, or handled natively by LightGBM. The “latest transaction” fields are where March renewals enter the features: see Leakage in the Report.

The feature matrix

After aggregating each table to one row per subscriber and joining, the labelled data is 946,686 rows × 35 columns (msno + is_churn + 33 model features). Every feature is float32, so missing values stay as NaN. It is split 70 / 10 / 20 into train (662,679), validation (94,669) and test (189,338) rows. The unlabelled Kaggle test matrix is 24,274 × 34 (no target).
