The five raw tables

The KKBOX churn data comes as five CSV files. Two hold the subscribers we predict for; three describe them. We turn every table into one row per subscriber and left-join them, so no subscriber is dropped. The coverage column shows the share of the labelled subscribers who appear in each table.

Columns in each raw file

27 columns across the five files (2 + 1 + 6 + 9 + 9). msno is in every file and is the join key. Data types are what pandas infers from the CSV; dates are stored as YYYYMMDD integers and parsed during feature engineering.

The feature matrix

After aggregating each table to one row per subscriber and joining, the labelled data is 946,686 rows × 35 columns (msno + is_churn + 33 model features). Every feature is float32, so missing values stay as NaN. It is split 70 / 10 / 20 into train (662,679), validation (94,669) and test (189,338) rows. The unlabelled Kaggle test matrix is 24,274 × 34 (no target).
